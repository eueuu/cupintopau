# Anotações sobre o CSS

## Dúvidas sobre partes específicas do código

### Efeito Hover
```css
.musica-card:hover {
    background: #3E3E3E;
}
```
**P:** "mas esse efeito de hover não faz com o js e não com o css?"  
**R:** Não! O :hover é um recurso do CSS. Para efeitos simples como mudar cor quando passa o mouse, o CSS é suficiente. JavaScript seria necessário para efeitos mais complexos.
